# Images go here

Drop files in with these exact names and the landing page will pick them
up automatically — nothing else to configure.

## hero.jpg  (required for the hero photo)
The full-bleed background behind "More than a haircut." Landscape,
at least 1920×1080. A dark gradient is layered over it automatically so
white text stays readable — the image can be a normal, not-especially-dark
photo. A slow zoom (Ken Burns effect) is applied automatically too.

Good subjects: Ralf's kit laid out, mid-cut close-up, the chair set up
in a client's space — anything that's actually your business, not a
generic stock lounge.

## band.jpg  (optional — a second photo moment further down the page)
A wide horizontal strip shown between "The Ralf Standard" and "Booked
with confidence," with a gentle parallax drift as you scroll. If this
file doesn't exist, that section just doesn't render — safe to skip.

## Formats
.jpg or .png both work. Keep hero.jpg under ~500KB if you can (export
at "80% quality" from most photo editors) so the page still loads fast —
Next.js doesn't auto-optimize plain files referenced this way.
